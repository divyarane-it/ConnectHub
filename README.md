
# ConnectHub – Contact & Task Manager

ConnectHub is a responsive web application built using HTML,
CSS, and JavaScript. It combines a contact form with validation
and a dynamic to-do list in one simple interface.

## Features

- Contact form with required fields
- JavaScript email validation
- Success and error messages
- Responsive layout for desktop and mobile
- Add new tasks dynamically
- Mark tasks as completed
- Delete tasks
- Task counter for remaining tasks

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- DOM Manipulation
- Media Queries

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Use the contact form and to-do list.

## Learning Outcomes

This project demonstrates form validation, JavaScript events,
DOM manipulation, responsive design, Flexbox, and CSS Grid.

## Note

The contact form displays a validation message locally.
It does not send messages to an actual email inbox.
